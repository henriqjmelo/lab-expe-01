## Sobre este repositório

Este repositório reúne **todos os laboratórios da disciplina** ao longo do semestre. Cada laboratório fica numa pasta própria, com seu próprio README, código e relatório — mas todos compartilham o mesmo GitHub Projects (v2) como quadro Kanban: o board acompanha o grupo do primeiro ao último laboratório, sem recriar um novo a cada entrega.

## Convenções que valem para todos os laboratórios

1. Todo commit referencia o número da Issue correspondente na mensagem (ex.: `#12 implementa consulta GraphQL`) — a correção é feita a partir do board, e commits sem essa referência não são considerados na avaliação.
2. Nenhuma tarefa fica como *draft issue* solta — todas viram Issues reais do repositório, vinculadas ao Project, com um responsável (*assignee*) definido.
3. Cada entrega vai numa branch própria, mergeada via Pull Request referenciando a Issue correspondente.

Objetivo, questões de pesquisa, política de WIP e instruções de execução de cada laboratório estão no README da respectiva pasta.
